# Cubmail

Cliente de correo para Windows 11 de [Cubetic](https://github.com/Cubetic).

Este repositorio solo contiene las versiones compiladas. Descarga la última desde
[Releases](../../releases/latest):

- **Cubmail_Setup_X.Y.Z.exe**: instalador. Si ya tienes Cubmail instalado, lo actualiza conservando la
  configuración y el correo.
- **Cubmail_X.Y.Z_portable.zip**: versión portable (descomprimir y ejecutar `Cubmail.exe`).
- Los ficheros **.sha256** contienen la huella para comprobar que la descarga no se ha alterado.

Cubmail busca actualizaciones automáticamente una vez al día (se puede desactivar en Archivo › Opciones ›
General) y también desde Archivo › Acerca de › «Buscar actualizaciones».
